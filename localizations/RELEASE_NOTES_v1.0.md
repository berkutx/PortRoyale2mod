# Localization packages v1.0

First public Port Royale 2 localization package release for the exact English
GOG 1.1.2.3 executable.

Included languages:

- German / Deutsch
- Spanish / Español
- Polish / Polski
- Russian / Русский

The packages contain translated string tables and only compatible declared
font/audio assets. They do not contain or replace `PR2.exe`, DLLs, or CPR
archives. Open any `*.pr2loc.zip` with a normal ZIP archiver to review
`manifest.json` and UTF-8 `strings.jsonl` before installing it.

Install with the current **PR2 Addon Configurator.exe**: select a language,
press **Download & install**, then **Activate**. The Configurator pins the v1.0
asset name, size, and SHA-256 and performs the complete package validation
before installation. Manual **Install local...** remains supported.

Supported executable SHA-256:
